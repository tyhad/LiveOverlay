# Implementation Plan: Optimization, Security & Documentation Refactor

## Objective
Refine the LiveOverlay project by optimizing the frontend assets, securing the backend API, cleaning up the routing, and providing comprehensive documentation for end-users.

## Tasks

### 1. Routing & File Cleanup
- **Remove** `public/index.html` (the old boilerplate).
- **Rename** `public/gui.html` to `public/index.html` so that it serves as the default root page.
- **Update Backend**: Ensure the ElysiaJS server (`src/index.ts`) serves the new `public/index.html` at the root `/` route.

### 2. Git Configuration & State Management
- **Ignore Local State**: Add `settings.json` to the `.gitignore` file to prevent local stream data from being pushed to the repository.
- **Template File**: Create a new file named `settings.example.json` containing default dummy data. This serves as a template for new installations.

### 3. API Security (Simple Protection)
To prevent unauthorized users on the same network from changing the overlay text:
- Modify `src/index.ts` to restrict the server listener to local loopback (bind to `127.0.0.1` or `localhost`), ensuring the Control Panel and API are only accessible from the machine running the stream.
- *(Optional but recommended)*: Implement a simple environment variable or constant (e.g., `const SECRET_TOKEN = "your-secret"`) and require this token in the `Authorization` header for the `POST /api/settings` endpoint. Update the frontend `fetch` call to pass this token.

### 4. Frontend Optimization (Remove CDNs)
Currently, `gui.html` (soon to be `index.html`) and `overlay.html` rely on Tailwind CSS via CDN.
- **Remove** the `<script src="https://cdn.tailwindcss.com"></script>` tag from both HTML files.
- **Link Local CSS**: Add `<link rel="stylesheet" href="/styles.css">` to the `<head>` of both files. This ensures they use the compiled CSS generated by the existing Bun/Tailwind build script, improving load times and consistency.

### 5. Documentation (`README.md`)
Rewrite the `README.md` to be user-friendly for streamers. It must include:
- **Project Overview**: Brief description of LiveOverlay.
- **Installation Guide**: Prerequisites (Bun) and the install command (`bun install`).
- **Usage Guide**: Command to start the server (`bun run dev` or `bun start`), and how to access the Control Panel (`http://localhost:3000`).
- **OBS Integration**: Clear, step-by-step instructions on how to add `http://localhost:3000/overlay.html` as a "Browser Source" in OBS Studio (including setting width/height and enabling "Transparent Background" if applicable).

## Execution Notes for AI
- Focus on cleaning up existing code rather than adding major new features.
- Ensure the build scripts (`bun run build:css`) still function correctly and map to the HTML files.
