# Logo Tim F1 Team Radio

Folder ini menyimpan logo tim yang ditampilkan pada tampilan **Chat Notification → F1 Team Radio**.

## Nama file yang dikenali
`f1`, `ferrari`, `redbull`, `mclaren`, `mercedes`, `astonmartin`, `alpine`, `williams`, `racingbulls`, `haas`, `audi`, `cadillac`.

## Prioritas ekstensi
`.png` → `.webp` → `.svg`

Artinya, kalau kamu ingin memakai logo resmi PNG, cukup taruh misalnya `ferrari.png` di folder ini **tanpa perlu menghapus** `ferrari.svg` bawaan — file `.png` akan otomatis diprioritaskan. Kamu juga boleh langsung menimpa file `.svg` bawaan.

Server memeriksa isi folder tiap ±5 detik secara otomatis (tidak perlu restart).
